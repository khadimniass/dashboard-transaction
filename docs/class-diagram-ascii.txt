╔══════════════════════════════════════════════════════════════════════════════════════════╗
║                          RELATIONS PRINCIPALES                                           ║
╠══════════════════════════════════════════════════════════════════════════════════════════╣
║                                                                                          ║
║  1. Transaction ◆──> Customer (composition 1:1)                                         ║
║     Une transaction contient exactement un client                                       ║
║                                                                                          ║
║  2. Transaction ──> TransactionType (association)                                       ║
║     Une transaction a un type (enum)                                                    ║
║                                                                                          ║
║  3. Transaction ──> TransactionStatus (association)                                     ║
║     Une transaction a un statut (enum)                                                  ║
║                                                                                          ║
║  4. User ──> UserRole (association)                                                     ║
║     Un utilisateur a un rôle (ADMIN ou USER)                                            ║
║                                                                                          ║
║  5. AuthResponse ◆──> User (composition)                                                ║
║     Une réponse d'auth contient un utilisateur                                          ║
║                                                                                          ║
║  6. TransactionService - - -> Transaction (dépendance 1:n)                              ║
║     Le service gère plusieurs transactions                                              ║
║                                                                                          ║
║  7. AuthService - - -> User (dépendance 1:0..1)                                         ║
║     Le service gère 0 ou 1 utilisateur connecté                                         ║
║                                                                                          ║
║  8. ExportService - - -> Transaction (dépendance 1:n)                                   ║
║     Le service exporte plusieurs transactions                                           ║
║                                                                                          ║
